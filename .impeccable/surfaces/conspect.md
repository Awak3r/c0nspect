# Conspect interface

Scope: owner login, library, project management, API-key settings and owner/public note readers. Operate for working screens, Read for notes. The user's explicit direction is black and white; existing permissions, data and form actions are not redesign material.

## Direction contract

**THESIS:** a quiet personal library. Task hierarchy and the reading column replace tinted panels and repeated card grids. No marketing claims or ornamental dashboards.

**OWN-WORLD:** white/near-white and black with neutral grays only; crisp rules, workhorse UI typography, native form controls. Serif prose stays confined to the note reading column. No gradients, decorative shadows or colored syntax.

**STORY:** sign in, find a project, read a note; organization and uploads stay visibly separate from reading. Error, empty and destructive states remain explicit in text, not color alone.

**FIRST VIEWPORT:** compact masthead; login identity and form side by side on desktop, one column on mobile. The library keeps search above its project list, with new-project creation in a separate side area. Readers retain a calm 65–75-character column and ordinary navigation only.

**FORM:** code-led refinement using the published Impeccable Operate/Read guidance. The launcher is unavailable, so no concept seed or engine verdict is claimed. System light/dark preference follows the reading environment; both are strictly grayscale.

**FINISH:** inspect representative desktop/mobile renders, document the actual CSS tokens in DESIGN.md, compile and deploy only the application with the existing release available for rollback. No long test suite or live fixture creation.
